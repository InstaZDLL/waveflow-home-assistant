# Changelog

The app runs the WaveFlow Server image of the same version. What changed in
the server is in its [release notes](https://github.com/InstaZDLL/waveflow-server/releases).

## 2.2.2

- First version of the app, on WaveFlow Server
  [2.2.2](https://github.com/InstaZDLL/waveflow-server/releases/tag/v2.2.2):
  the first release whose image starts on a data folder Home Assistant
  provides, and whose playback no longer stops after a minute in the desktop
  app.
