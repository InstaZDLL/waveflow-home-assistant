# WaveFlow Server

**Your music, everywhere you listen.** A self-hosted music server with a web player built in, and the OpenSubsonic API your apps already speak.

- Albums, artists, folders, search, synced lyrics, mixes and listening statistics in the web player.
- Symfonium, Feishin, DSub, Juliet and other Subsonic apps work as they are.
- Music read from Home Assistant's `media` and `share` folders, never rewritten.
- The audio of every lossless file is measured: a FLAC that was once an MP3 shows as one.

See the **Documentation** tab to get started.
